# 界面规范

## 视觉层级

界面使用中性色表面、细边框与青灰色流量图表。状态色仅用于成功、警告、错误和危险操作。浅色与暗色主题共享语义变量，交互边框与容器分隔线分别使用 `--control-border` 和 `--border`。

| 元素           | 字号                   | 字重      | 布局约束                         |
| -------------- | ---------------------- | --------- | -------------------------------- |
| 页面标题       | 24 px；移动端 21–22 px | 700       | 图标 23 px，间距 10 px           |
| 弹窗标题       | 18 px                  | 600       | 关闭按钮独立占位，长标题允许换行 |
| 表单分区标题   | 15 px                  | 600       | 与字段间距 20 px                 |
| 正文、表单标签 | 14 px / 13 px          | 400 / 500 | 标签与控件间距 8 px              |
| 表头、紧凑操作 | 13 px                  | 500       | 行高 20 px                       |
| 辅助信息       | 12 px                  | 400       | 保留费用、状态、时间及操作约束   |
| 流量汇总       | 26 px；移动端自适应    | 600       | 数值与单位分层，数字采用等宽数值 |

字体优先使用本机 Inter、系统 UI 字体、PingFang SC 与 Microsoft YaHei UI，代码和密钥指纹等技术内容使用 Cascadia Code / Consolas。无需远程字体请求。图标采用 Lucide，常规描边宽度为 1.65；控件图标与文字按视觉中心对齐。

表格正文为 14 px，表头和状态标签为 13 px。防火墙应用名称、日志内容使用常规字重，资源名称按需要使用 600 字重。命令、密钥指纹、CIDR 等技术字符串可使用等宽字体。次级规格、日期范围和流量额度保留独立的辅助层级。

首列贴近容器左侧内边距，末列与右侧内边距对齐；末列按内容确定紧凑宽度，剩余空间分配给中间列。同列的表头与数据使用相同对齐规则。操作按钮保持同行，窄屏卡片可换行。长日志详情完整换行。

账户列表的“验证”和“删除”均使用图标与文字按钮，高度保持一致，同行排列；删除按钮使用危险操作色，点击后进入移除凭证确认。

实例列表的状态列仅显示状态标签，与同一行数据垂直居中。桌面网络列按完整地址确定最小宽度，IPv6 与复制按钮保持单行；窄屏卡片允许地址换行，避免页面横向溢出。

桌面实例表的本月流量区域保持 180 px 宽度，完整显示用量、百分比、进度及额度。实例概况只保留数量统计。两个面板的移动端顶栏隐藏面包屑，退出登录按钮统一为 40 px、18 px 图标；触控设备保留至少 44 px 的点击区域。

流量统计和防火墙的实例筛选只显示实例名，宽度不超过 240 px，窄屏时随容器缩小。触发器中的长名称使用省略号，展开后可查看完整名称并搜索。

页面使用一级路径 `/instances`、`/launch`、`/ips`、`/firewall`、`/traffic`、`/audit`、`/settings`，支持直接访问、刷新、前进和后退。不保留原 `/lightsail` 路径映射；根路径默认进入 `/instances`。

登录与初始化页复用两仓库相同的 `auth.css`，外观选择器与登录按钮等宽。表单使用 `Form`，输入使用 `Input`；仅登录页显式启用 `allowPasswordManager`，其余字段（含 Token 和云密钥）及表单均关闭自动填充，并提供常见密码管理器的忽略标记。原生输入由 `Field` 补齐标记，SSH 终端输入沿用相同规则。

业务页面还按 [1Password 官方整页忽略规则](https://www.1password.dev/web/compatible-website-design) 给 `body` 设置 `data-1p-ignore`，覆盖 Portal 和动态输入。登录、初始化页解除此标记，登录成功后恢复；切换在渲染提交阶段同步完成。

桌面 `scrollbar-gutter: stable` 已预留滚动条空间，Radix 锁定滚动时不再重复补偿，避免卡片宽度变化；移动端与不支持该属性的浏览器保留原有补偿。

## 控件与状态

- 普通按钮、输入框和下拉选择器的单行基准高度为 40 px；紧凑按钮及图标按钮为 34 px。多行选项允许增高。
- 输入框使用焦点边框与浅色光环，滚动正文保留焦点余量；独立按钮和链接保留外部键盘焦点标记。悬停、选中、键盘焦点和禁用状态分别处理。
- 下拉选项保留选中标记；键盘活动项使用更明显的背景。长选项换行，选中标记不压缩。选项列表按视口空间定位，不改变页面滚动位置。
- 实例、账户、区域、镜像和套餐选择器支持搜索、无匹配结果提示、方向键选择、Enter 确认与 Esc 关闭；中文输入法组合输入期间不触发选择。统计周期使用分段控件，支持方向键及 Home、End 切换。
- 实例筛选置于表格工具栏，部分选中时全选框显示中间状态。概况标签和数字使用相同字号与行高。
- 实例操作菜单支持方向键、Home、End 和 Esc。键盘移动至超出菜单可视区域的操作时，同步滚动菜单；关闭后恢复触发按钮焦点。
- 请求期间保留按钮标签、尺寸和既有数据，通过禁用及透明度变化反馈处理状态，不预留加载图标空位。
- 空状态仅展示对应标题和必要操作；说明文字由调用页面显式提供。错误、费用与不可逆操作提示允许完整换行。
- 支持 `prefers-reduced-motion`，关闭非必要动画与过渡。

## 表面与滚动

桌面侧栏宽 216 px、顶栏高 64 px，内容区内边距 32 px，最大宽度 1920 px。卡片及表格容器圆角为 10 px，普通控件为 6 px，弹窗为 12 px；弹出菜单使用轻量阴影。一般内容区使用浏览器原生滚动，图表内部使用紧凑横向滚动；SSH 保留独立滚动组件。

账户列表与表单、移除确认、自动关机和防火墙弹窗按内容确定高度，并受可用视口限制。长内容由弹窗正文滚动。流量与 SSH 使用稳定的工作区高度；独立流量页面的每日明细随页面滚动，弹窗内设置最大可视高度。每日明细默认展开并按日期倒序，图表按日期顺序展示，提示框跟随指针并避让边缘。SSH 内部尺寸由 FitAddon 管理，边框与内边距仅放在外层容器。

## 响应式布局

- 900 px 及以下：侧栏转为导航抽屉；实例列表使用 shadcn/ui Card（radix-vega）的 `size="sm"`，顶部名称和状态，其下流量占满卡片宽度，以 14 px 数值、额度、进度与明细入口优先展示。网络独占一行，规格与账户分为双列，操作集中于底部。全选位于筛选栏。其余较宽表格在自身容器内滚动。
- 600 px 及以下：资源表格转为信息卡片，表单采用单列；长名称、IPv6、CIDR 和日志详情完整换行。创建页标题与操作允许分行。
- 320 px 窄屏：保持核心操作可达，允许工具栏换行；图表在自身区域横向滚动，页面不产生整体横向滚动。
- 移动端防火墙列表随页面滚动，弹窗继续由正文容器控制滚动，避免多层滚动竞争。

## 维护与验证

公共交互使用 Radix Dialog（弹窗和移动导航）、Select、Dropdown Menu、Popover（时间与月份）、Toggle Group、Tooltip；可搜索选择器由 Radix Popover + cmdk 提供。视口避让、嵌套焦点、键盘导航、Esc 和滚动锁定由成熟组件处理。

与 Aliyun Panel 保持 `tokens.css`、`foundation.css`、`controls.css` 以及 `Modal`、`Sidebar`、`Select`、`ActionMenu`、`TimePicker`、`SegmentedControl`、`Tooltip` 的内容一致。两个仓库独立构建，公共组件修改须同步，不依赖彼此的本地路径。字号、字重和 120 / 150 / 180 ms 过渡统一由变量控制；触屏主要操作至少 44 px，移动端搜索输入为 16 px，页面、导航和弹窗保留设备安全间距。

`inventory.css` 和 `InventoryTrafficHeading` 也在两个项目中保持一致，统一实例列表的信息顺序和流量展示，避免不同页面重新覆盖卡片布局。

`ShadcnCard` 直接复用已安装的标准 Card 源码，来源见 [shadcn/ui Card](https://ui.shadcn.com/docs/components/radix/card)。`InventoryTable` 根据宽度切换标准 `CardHeader / CardTitle / CardAction / CardContent / CardFooter` 组合；桌面表格和手机卡片复用数据、选择状态及操作处理。`shadcn.css` 仅加载 Tailwind 主题与工具类，不引入 Preflight；颜色和字号映射到面板已有变量。

主题变量位于 `src/styles/tokens.css`；`foundation.css` 管理基础元素，`layout.css` 管理导航及布局，控件、表单、表格、反馈和弹窗按文件拆分；`traffic.css` 管理流量视图，`responsive.css` 管理业务组件的窄屏布局。新增组件应复用 `Field`、`Input`、`Select`、`SegmentedControl`、`Modal`、`PendingButton` 等基础控件，避免叠加独立覆盖层。

界面修改须核查全部主路由、弹窗、菜单、浅色与暗色主题，以及 320、390、768 px 和桌面视口。验证范围包含长内容、加载、空状态、错误提示、禁用状态、键盘焦点、菜单边界及 SSH 全屏。业务测试、类型检查和生产构建须同时通过。

## 设置页

日报时间使用与 Aliyun Panel 相同的 `TimePicker` 组件及现有控件样式，通过独立的小时、分钟选择器设置时间，支持确认、Esc、点击外部关闭和视口边缘避让。消息预览的资源标识仅显示实例名。

侧栏设置页集中展示 AWS 账户管理、登录有效期、Telegram 通知和最近投递记录，沿用原有表单、表格和弹窗组件。顶部只保留面包屑及退出操作，不显示全局区域或账户选择器。账户列表直接显示在设置页，添加和移除仍使用原有确认流程。登录有效期使用原有续期接口，仅更新当前浏览器会话；期限选择器与保存按钮同行对齐。

通知类型按 Lightsail 已实现的功能提供，消息示例随类型切换，预览与实际发送共用格式。默认勾选资源操作失败、流量保护关机、公网 IP 变化和每日汇总。标签、输入框、选择器与按钮按行对齐；窄屏下表单和通知类型网格自动调整列数。Bot Token 为密码字段，其余普通输入继续禁止密码管理器自动填充。测试通知使用已保存配置；存在未保存修改时禁用测试按钮。投递记录随服务端事件更新，列表仅展示消息标题，成功投递不显示尝试次数，异常详情位于投递状态列。账户操作列保留固定宽度；通知时间、标题和状态列按约 28%、52%、20% 分配，并限制时间及状态列的最小宽度。窄屏下转换为信息卡片。
